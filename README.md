# 🏥 Medical AI Assistant

AI-powered radiology report generation system.

## 🚀 Features
- JWT Authentication
- Role-based access (Doctor/Admin)
- Image upload
- AI-generated reports
- PDF export

## 🛠 Tech Stack
- Frontend: React.js
- Backend: FastAPI
- Database: PostgreSQL
- AI: Vision API

## ▶️ Run Locally

### Backend
cd backend
venv\Scripts\activate
uvicorn main:app --port 8020

### Frontend
cd frontend
npm install
npm start
